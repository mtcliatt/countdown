# Countdown

A mobile-friendly countdown from March 6, 2026 to May 25, 2027.

Shows today's local date, days passed, days remaining, and percentage complete. Updates automatically and handles daylight-saving changes using calendar dates.

## View locally

Open `index.html` in your browser. No dependencies or build step are required.

## Publishing

Keep this project local unless publishing is explicitly requested. Changes should not be deployed or pushed automatically.
